# RAG 调优笔记（示例）

> 这是一篇示例笔记，由「一键导入演示数据」创建，展示笔记的 Markdown 渲染效果。

## 检索质量抓手

| 手段 | 作用 | 经验值 |
|---|---|---|
| 混合检索（向量 + BM25 + RRF） | 兼顾语义与关键词 | 默认开启 |
| 查询分解 | 长问题拆成子查询 | 复杂问题收益明显 |
| 上下文压缩 | 控制送入 LLM 的长度 | token 预算 4000 起 |

## 常见问题排查

1. **引用率低**：先查文档解析状态，再看意图分类是否落错通道
2. **回答冗长**：在回答方案中约束「先结论后步骤」
3. **召回不准**：确认 chunk 500/50 切分是否适合当前文体，表格类文档建议单独调参

## 本周结论

演示知识库的三篇文档（员工手册 / 产品目录 / 权限矩阵）在混合检索下引用率稳定，
可作为后续新文档的基线对照。
