# 产品目录（演示文档）

本文档用于演示 HFusionHub 知识库问答能力，产品与价格均为虚构示例。

## 产品总览

公司提供三档订阅产品：基础版、专业版、旗舰版。

### 基础版（免费）

- 单用户
- 3 个知识库，每个知识库最多 50 篇文档
- 基础问答（每日 20 次）
- 社区支持

### 专业版（99 元/月/用户）

- 单用户起，按用户计费
- 50 个知识库，每个知识库最多 500 篇文档
- 高级 RAG 检索（混合检索 + 重排序）
- 工具调用与 Agent 自动化
- 每日 1000 次问答
- 邮件支持，7×24 小时

### 旗舰版（399 元/月/用户）

- 含专业版全部功能
- 不限知识库数量
- 多租户隔离与细粒度权限
- 自定义模型接入（DeepSeek / Ollama / OpenAI 兼容）
- 专属客户成功经理
