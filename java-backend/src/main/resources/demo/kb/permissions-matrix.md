# 权限矩阵（演示文档）

本文档说明 HFusionHub 各角色的权限范围，内容为虚构示例。

## 角色总览

系统包含三种业务角色：普通用户、AI 配置员、管理员，以及一种待分配状态。

### 待分配（新注册默认）

- 仅可登录并查看等待分配页面
- 不能访问知识库、对话、模型等功能
- 需联系管理员分配角色

### 普通用户

- 创建与管理自己的知识库
- 上传文档、发起解析与问答
- 使用对话、查看 AI 任务记录
- 查看成本仪表板（个人维度）

### AI 配置员

- 包含普通用户全部权限
- 管理 Prompt 模板与测试台
- 配置模型供应商（DeepSeek / Ollama 等）
- 查看 RAG 观测与质量评估
- 管理工具中心（新建低代码工具）

### 管理员

- 包含 AI 配置员全部权限
- 用户与权限管理（分配角色、禁用账号）
- 插件管理（安装、启用、禁用）
- 功能开关（意图路由、能力开关）
- 系统级配置与租户管理

## 关键规则

- 超级管理员（admin）不能被降级，也不能被其他账号替代
- 所有删除操作先进入回收站，保留 7 天
- 文档向量化使用的模型由系统统一管理，用户级模型配置只影响问答
