# 员工手册（演示文档）

本文档用于演示 HFusionHub 知识库问答能力，内容为虚构示例。

## 工作时间

公司实行弹性工作制，标准工作时间为周一至周五 09:30 - 18:30，午休 12:00 - 13:30。
员工可在保证每日 8 小时工作时间的前提下，于 09:00 - 10:00 之间灵活到岗。

## 年假政策

- 入职满 1 年：每年 5 天年假
- 入职满 3 年：每年 10 天年假
- 入职满 5 年：每年 15 天年假
- 年假按自然年计算，当年未休完的可结转至次年，最多结转 5 天
- 申请年假需提前 3 个工作日通过 OA 系统提交，直属上级审批

## 报销流程

1. 出差或业务支出发生后 30 天内提交报销申请
2. 在 OA 系统填写费用类型、金额、事由并上传发票
3. 金额在 2000 元以内的由部门主管审批；超过 2000 元的需再经财务部审批
4. 审批通过后 5 个工作日内打款至工资卡
