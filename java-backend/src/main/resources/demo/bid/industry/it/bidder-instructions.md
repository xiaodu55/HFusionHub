# 投标人须知

本须知适用于云谷智慧园区数据中心建设项目招标。投标人应仔细阅读并充分理解招标文件全部内容，未作实质性响应的投标文件将被否决。

## 资质要求

投标人须具备电子与智能化工程专业承包一级资质，并持有 ITSS 信息技术服务运行维护标准认证与 ISO/IEC 27001 信息安全管理体系认证证书。项目负责人须具备信息系统项目管理师（高级）证书，资质证书须在投标有效期内。

## 财务要求

投标人近三年财务状况良好，资产负债率不得高于 75%。投标人须提供经审计的近三年财务报表作为证明材料。

## 业绩要求

投标人近三年须至少完成两项单项合同金额不低于 2000 万元的数据中心或信息系统集成类项目业绩，须提供合同及验收报告（含业主验收证明）。

## 密封与签署要求

投标文件须按招标文件要求密封、签署并加盖投标人电子签章。未按要求密封、签署的投标文件将被拒收。

## 投标文件份数

投标文件须提交正本一份、副本三份，并同时通过电子招投标平台上传加密电子投标文件。正副本内容不一致时以正本为准。
