# 评标办法

本项目评标采用综合评分法，评标委员会依据招标文件规定的评审因素和标准对投标文件进行评审。综合评分法满分 100 分。

## 评分方式

本项目采用综合评分法进行评标，综合评分法满分 100 分。评标委员会成员独立评分，取算术平均值为投标人最终得分。

## 评分标准

技术方案 40 分，投标报价 30 分，实施与运维能力 20 分，企业综合实力 10 分。满足招标文件要求且报价最低的投标报价为评标基准价。

## 废标条款

投标报价超过招标预算上限 5800 万元的，评标委员会应当否决其投标；未按要求提供投标保证金、未提供完整实施方案、经认定属于串通投标或不具备招标文件要求的资质条件的，均应否决其投标。

## 得分相同处理

得分相同时，按投标报价由低到高确定排名；报价仍相同的，按技术方案得分高者优先确定排名。

## 实质性响应要求

投标文件须对招标文件提出的全部实质性要求和条件作出响应，未作实质性响应的投标将被否决。实质性要求包括资质、系统集成范围、实施工期、服务等级（SLA）等。
