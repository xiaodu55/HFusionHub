## [technical-approach] 技术方案总体思路

我方针对滨海园区智能化改造项目，采用「统一规划、分步实施、平台集成、安全可控」的总体思路：
以园区综合管理平台为核心，集成视频监控、门禁一卡通、楼宇自控、信息发布、能耗管理等子系统，
实现跨系统联动与统一运维。技术架构采用云边端三级：边缘层完成数据采集与控制，平台层完成
汇聚、存储与算法分析，应用层面向园区运营与管理者提供可视化服务。

## [technical-subsystems] 主要子系统实施方案

- **视频监控系统**：采用全数字高清网络摄像机（不低于 400 万像素），园区周界、出入口、重要
  区域全覆盖，存储满足 90 天本地录像，支持行为分析（入侵检测、区域入侵、徘徊检测）。
- **门禁一卡通系统**：统一发卡平台，支持人脸识别 + 刷卡双因子认证，覆盖园区各出入口与重点
  机房，记录可审计追溯。
- **楼宇自控系统（BAS）**：对中央空调、给排水、电梯、照明实施集中监控与节能策略，
  目标节能率不低于 15%。
- **综合布线系统**：六类非屏蔽双绞线，水平链路满足 250MHz 带宽，主干采用单模光纤，
  支持未来万兆升级。

## [technical-schedule] 实施进度计划

项目总工期 180 日历天，关键里程碑：
- 第 1–30 天：深化设计、设备采购、进场准备
- 第 31–90 天：管线敷设、机房建设、设备安装
- 第 91–150 天：系统联调、软件平台部署、单系统测试
- 第 151–180 天：联合调试、试运行、培训、竣工验收
我方承诺关键节点周报同步，必要时增派施工班组压缩工期。
