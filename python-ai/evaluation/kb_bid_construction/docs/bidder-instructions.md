# 投标人须知

本须知适用于蓉城市政道路提升改造工程施工招标。投标人应仔细阅读并充分理解招标文件全部内容，未作实质性响应的投标文件将被否决。

## [qualifications] 资质要求

投标人须具备市政公用工程施工总承包二级及以上资质，并持有有效的安全生产许可证。拟派项目负责人须具备市政公用工程专业一级注册建造师执业资格，资质证书、安全生产许可证须在投标有效期内。

## [financial] 财务要求

投标人近三年财务状况良好，资产负债率不得高于 80%。投标人须提供经审计的财务报表作为证明材料。

## [performance] 业绩要求

投标人近五年须至少完成两项单项合同金额不低于 3000 万元的市政道路类工程项目业绩，须提供中标通知书、合同及竣工验收证明。

## [seal-requirements] 密封与签署要求

投标文件须按招标文件要求密封、签署并加盖投标人公章，密封处应加盖密封章或法人签字。未按要求密封、签署的投标文件将被拒收。

## [bid-preparation] 投标文件份数

投标文件须提交正本一份、副本四份，正副本内容不一致时以正本为准。投标文件须同时递交电子版一份（U 盘存储）。
